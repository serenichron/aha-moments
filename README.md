# Aha Moments with Liana

A landing page for "Aha Moments with Liana" - an emotional guidance service for overwhelmed parents.

## Overview

This is a Bootstrap-based landing page designed to guide emotionally overwhelmed parents toward discovering and enrolling in Liana's signature 2-session program with a personalized plan.

## Features

- **Responsive Design**: Mobile-first approach, works on all devices
- **Bootstrap 5.3**: Modern CSS framework with utility classes
- **Custom Styling**: Warm, calming color palette with elegant typography
- **Smooth Interactions**: Scroll animations, form handling, navigation effects

## Sections

1. **Hero Section** - Attention-grabbing headline with emotional resonance
2. **Categories** - Visual icons representing core values
3. **Problem Section** - Validates parent struggles and builds empathy
4. **What This Is/Isn't** - Clear expectations setting
5. **How It Works** - 3-step process explanation
6. **About Liana** - Personal story and credibility
7. **Benefits** - Accordion-style value presentation
8. **Testimonials** - Social proof from parents
9. **Signup Form** - Lead capture with email
10. **FAQ** - Common questions addressed
11. **Footer** - Contact and links

## Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, Grid
- **Bootstrap 5.3** - Framework (via CDN)
- **Font Awesome 6.5** - Icons (via CDN)
- **Google Fonts** - Cormorant Garamond & Nunito

## Getting Started

1. Clone the repository
2. Open `index.html` in a browser
3. No build process required - static files

## Customization

### Colors
Edit CSS variables in `css/style.css`:
```css
:root {
    --primary: #7c9a92;
    --secondary: #e8c4a2;
    --accent: #c9a87c;
    /* ... */
}
```

### Content
Edit text directly in `index.html`

### Images
Replace placeholder elements with actual images in `images/` folder
